# 📊 Sales Performance Analysis – Power BI

## 📌 Project Overview

This project focuses on analyzing sales data using **Microsoft Excel** and **Power BI** to identify important sales trends, product performance, customer behavior, regional performance, and payment patterns.

The project includes data cleaning and preparation in Excel, followed by interactive dashboard development in Power BI.

## 🎯 Objectives

* Analyze overall sales performance
* Identify monthly sales trends
* Compare sales across different regions and categories
* Identify top-performing products and customers
* Analyze customer types and payment methods
* Understand order and quantity patterns
* Analyze discount and shipping cost patterns
* Build an interactive Power BI dashboard for business insights

## 🛠️ Tools & Technologies

* **Microsoft Excel** – Data cleaning and preprocessing
* **Power BI** – Data visualization and dashboard development
* **DAX** – Measures and calculations
* **GitHub** – Project documentation and version control

## 🧹 Data Cleaning & Preparation

The dataset was cleaned and prepared in Excel before importing it into Power BI.

The major data preparation steps included:

* Removed duplicate records
* Checked and handled missing values
* Replaced missing promotion values with `Unknown`
* Standardized date formats
* Standardized numerical and currency fields
* Formatted discount values as percentages
* Checked categorical values for consistency
* Removed redundant date column
* Filtered the dataset for the required number of records

## 📊 Key Analysis

The Power BI dashboard includes analysis such as:

* Total Sales
* Total Orders
* Total Quantity Sold
* Average Order Value
* Monthly Sales Trend
* Sales by Category
* Sales by Region
* Sales by Customer Type
* Sales by Payment Method
* Top 5 Products by Sales
* Top 5 Customers by Sales

* Sales vs Quantity

## 📈 Dashboard

The Power BI dashboard provides an interactive view of sales performance using:

* KPI Cards
* Bar Charts
* Column Charts
* Line Charts
* Donut Charts
* Matrix
* Slicers

Users can filter the dashboard based on dimensions such as **Order Date, Region, Category, Customer Type, and Payment Method**.

## 💡 Key Insights

The dashboard helps identify:

* Overall sales performance
* Monthly sales patterns
* Best-performing products and customers
* High-performing regions and categories
* Customer type contribution to sales
* Preferred payment methods
* Relationship between sales and quantity
* Impact of different discount ranges on sales
* Regional shipping cost patterns
